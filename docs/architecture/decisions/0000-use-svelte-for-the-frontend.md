# Use Svelte for the Frontend

## Context and Problem Statement

I want to build and self-host a personal website where I can make my portfolio available and share my writing. I need to decide whether to use a web framework and, if so, which framework I should use to build the frontend.

## Considered Options
- Angular
- Vue
- React
- Svelte
- No framework

## Decision Outcome

Given the limited scope of this project, I chose to use it as an opportunity to work with Svelte for the first time. Svelte is building up a reputation for being enjoyable to work with that I'd like to see for myself.
